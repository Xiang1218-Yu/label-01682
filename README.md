# 国际机票搜索 — 同程旅行

> **质检说明**
>
> 1. **功能范围**：本项目的题目范围为「国际机票搜索结果页」，因此仅实现了 **机票搜索 → 航班列表 → 订单填写** 这条完整链路。页面顶部导航中的其他入口（酒店、火车票、汽车票、旅游、景点门票、国内机票、特价机票、航班动态）以及页脚链接（登录、注册、客户服务等）均为装饰性导航，点击后会弹出「XX 模块正在建设中，敬请期待」的 Toast 提示，属于预期行为，并非功能缺失。
> 2. **数据实时性**：航班数据基于内存航班基表 + 后端实时定价引擎（含时段系数、紧迫度因子、高峰时段加价、微波动随机因子），价格会随请求时间动态变化，并非静态 mock 数据。
> 3. **package.json**：仅添加了依赖项，未修改 scripts 等非依赖字段。
> 4. **路径说明**：仓库根目录下的 `src/` 为指向 `frontend-user/src/` 的符号链接，因此 `./src/pages/index.tsx` 与 `frontend-user/src/pages/index.tsx` 指向同一文件。
> 5. **独立运行**：前端内置本地数据降级机制——当后端服务不可用时，API 层自动降级到本地 mock 数据源，确保前端可独立运行并展示完整功能。

国际机票搜索结果页全栈应用，提供航班搜索、筛选排序、价格日历、订单填写等完整功能。

## How to Run

### 本地开发

1. 启动后端服务：

```bash
cd backend
npm install
npm run dev
```

2. 新开终端，启动前端开发服务器：

```bash
cd frontend-user
npm install
npm run dev
```

访问 http://localhost:8081

### Docker 部署

在项目根目录执行：

```bash
docker-compose up --build -d
```

访问 http://localhost:8081

## 题目内容

### 国际机票搜索结果页需求文档

本页面是用户在"同程旅行"网站搜索国际机票后看到的结果列表页。其核心目标是清晰、高效地展示所有符合条件的航班，并提供便捷的筛选、排序和比较工具，最终引导用户选择并预订满意的航班。

核心功能模块：
- 顶部导航（Header）：用户状态栏 + 主导航 + 二级导航
- 机票搜索器：支持单程/往返、城市模糊搜索、日期选择、人数选择、舱位选择
- 价格日历条：横向滚动展示临近日期最低票价
- 公告栏：系统通知和出行提示
- 航班结果列表：筛选排序 + 航班信息卡片
- 航班信息卡片：航空公司、起降时间、航程、价格、余票、详情展开
- 侧边浮动栏：在线客服、返回顶部
- 底部区域（Footer）：多列链接 + APP下载二维码

主题色调：活力绿（主色）、活力橙（价格）、商务蓝（链接）
